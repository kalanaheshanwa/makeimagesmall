Why Image File Size Limits Matter

Image file sizes affect more than just whether your upload goes through. Oversized images slow down page load times, which directly impacts your Google search rankings. They also eat up storage, drain mobile data, and frustrate users who are just trying to see your content. On the flip side, images that are compressed too aggressively lose quality and look pixelated or blurry.

The sweet spot is finding the right balance — and that's exactly why tools that let you compress image online free have become so essential for creators, marketers, and web developers alike.

Image Size Limits for Major Social Media Platforms

Instagram

  • Maximum file size: 8 MB for photos
  • Recommended formats: JPEG, PNG
  • Best dimensions: 1080 x 1080px (square), 1080 x 1350px (portrait)
  • Instagram automatically compresses images that exceed its internal thresholds, often reducing quality noticeably

Facebook

  • Maximum file size: 10 MB per image
  • Recommended formats: JPEG, PNG
  • Cover photos: 820 x 312px recommended
  • Facebook recompresses uploads, so starting with an already-optimized image preserves more quality

Twitter / X

  • Maximum file size: 5 MB for JPEG and PNG, 15 MB for GIF
  • Recommended formats: JPEG, PNG, GIF, WebP
  • Images over the limit are rejected entirely, not just compressed

LinkedIn

  • Maximum file size: 5 MB for standard posts
  • Recommended formats: JPEG, PNG, GIF
  • Profile photo: Up to 8 MB
  • For company pages and articles, keeping images under 2 MB ensures faster loading for professional audiences

Pinterest

  • Maximum file size: 32 MB
  • Recommended formats: JPEG, PNG, WebP
  • Despite the generous limit, optimizing pins to under 1 MB dramatically improves load speed and saves performance

TikTok

  • Maximum file size for images in slideshows: 20 MB
  • Recommended format: JPEG, PNG
  • Clear, high-contrast images perform best in TikTok's fast-scrolling environment

Image Size Limits for Web & E-Commerce Platforms

WordPress

  • Default upload limit: Usually 2 MB to 64 MB depending on hosting
  • For best performance, aim for images under 200 KB for blog content
  • Large images are the number one reason WordPress sites score poorly on Google PageSpeed

Shopify

  • Maximum file size: 20 MB per image
  • Recommended formats: JPEG, PNG, WebP
  • Product images should ideally be under 500 KB to keep store loading fast and reduce cart abandonment

Squarespace

  • Maximum file size: 20 MB
  • Squarespace recommends keeping images under 500 KB for optimal performance

Wix

  • Maximum file size: 25 MB
  • Images over 1 MB will visibly slow Wix sites, especially on mobile

Email Marketing Image Size Recommendations

Email platforms like Mailchimp, Klaviyo, and ConvertKit don't always enforce strict limits, but best practice strongly recommends keeping email images under 1 MB — and ideally under 500 KB. Heavy images cause emails to load slowly, increasing the chance recipients delete before even seeing your message. Always use JPEG for photos and PNG for graphics with text or transparency.
