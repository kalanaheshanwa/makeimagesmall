Frequently asked questions

How does this image compressor work?
This tool uses your browser's Canvas API to re-encode images into WebP format — Google's modern image format built for the web. WebP achieves 25–80% smaller file sizes compared to JPG and PNG at the same visual quality.
Are my images uploaded to a server?
No. Everything runs inside your browser. Your images are never sent to any server — complete privacy, and faster processing since there's no upload time.
What image formats are supported?
You can compress JPG/JPEG, PNG, GIF, BMP, AVIF, TIFF, and WebP. All files are converted to WebP for maximum compression.
How much will it reduce my file size?
Typical results: JPG compresses 30–50%, PNG compresses 50–80%, GIF compresses 40–60%. Results vary by image content and your quality setting.
Will images lose quality after compression?
At the default quality setting of 82, the difference is invisible to the human eye. You can adjust the slider — anything above 75 is considered high quality for web use.
Is there a limit on how many images I can compress?
No limit. Compress as many images as you need in one batch, for free, forever.
Why use WebP instead of JPG or PNG?
WebP is supported by all modern browsers and provides significantly better compression. Smaller images = faster websites, better Google Core Web Vitals, and lower bandwidth costs.
Is this tool really free?
Yes, completely free. No subscription, no account, no watermarks, no limits. The tool is supported by ads.
